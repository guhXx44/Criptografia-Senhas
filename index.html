Módulo 02

🔤 Criptografia com letras

Substituímos cada letra do alfabeto por uma letra do dicionário QWERTY.

Alfabeto: abcdefghijklmnopqrstuvwxyz
Dicionário: qwertyuiopasdfghjklzxcvbnm
Texto codificado Aguardando...
Cada substituição aparecerá aqui.

Exemplo em Python

dicionario = "qwertyuiopasdfghjklzxcvbnm"

def codifica(senha):
    resultado = ""
    for letra in senha:
        posicao = ord(letra) - ord("a")
        resultado += dicionario[posicao]
    return resultado

print(codifica("marcelo"))
Módulo 03

💻 Conversor ASCII

ASCII é um padrão que associa códigos numéricos a letras, números, símbolos e caracteres de controle. Sua versão original contém 128 códigos, de 0 a 127.

A conversão aparecerá aqui.
Caracteres como á, ç e emojis não pertencem ao ASCII original. Eles são representados por padrões mais abrangentes, como Unicode.
Módulo 04

🔐 Codificação de senhas mistas

Agora usamos uma função com if e else. Letras de a até z são substituídas; outros caracteres permanecem iguais.

Resultado Aguardando...
Os passos aparecerão aqui.

Função Python modularizada

dicionario = "qwertyuiopasdfghjklzxcvbnm"

def codifica(senha):
    senha_criptografada = ""

    for letra in senha:
        if "a" <= letra <= "z":
            posicao = ord(letra) - ord("a")
            senha_criptografada += dicionario[posicao]
        else:
            senha_criptografada += letra

    return senha_criptografada

print(codifica("marcelo123"))
Módulo 05

#️⃣ Hash simples

Este algoritmo soma os códigos numéricos dos caracteres de um texto.

Hash por soma Aguardando...
Os cálculos aparecerão aqui.
Este hash não é seguro. Textos diferentes podem produzir o mesmo resultado, especialmente quando possuem os mesmos caracteres em ordens diferentes.

Exemplo em Python

def calcula_hash(senha):
    valor = 0
    for letra in senha:
        valor += ord(letra)
    return valor

print(calcula_hash("olecram"))
Módulo 06

⚙️ Hash didático de 32 bits

Multiplicamos o valor anterior por um fator, somamos o código do caractere e aplicamos o limite de 32 bits.

Decimal ...
Hexadecimal ...
Binário (32 bits) ...
Os cálculos aparecerão aqui.
Este algoritmo é didático, não é adequado para armazenar senhas reais. Multiplicar por 31 não equivale a adicionar um salt verdadeiro.

Exemplo em Python

def calcula_hash(senha):
    valor = 0

    for letra in senha:
        valor = valor * 31 + ord(letra)
        valor %= 2**32

    return f"0x{valor:08x}"

print(calcula_hash("Marcelo123!@"))

Módulo 10

📚 O que aprendemos?

🔐 Criptografia

Transforma informações para protegê-las. Em sistemas reais, a criptografia adequada permite recuperar os dados com a chave correta.

#️⃣ Hash

Produz um valor derivado de uma entrada. Funções hash criptográficas são projetadas para dificultar a recuperação da entrada e a busca por colisões.

🧂 Salt

É um valor aleatório usado no processamento de senhas. Não é simplesmente um número fixo multiplicando o resultado.

👤 Autenticação

Sistemas seguros verificam senhas utilizando mecanismos apropriados, sem precisar armazenar a senha original em texto simples.

🛡️ Boas práticas

Use senhas longas, únicas e difíceis de prever. Prefira um gerenciador de senhas e ative a autenticação em duas etapas quando disponível.

Importante: os algoritmos criados neste laboratório servem para aprendizado. Não devem ser usados para proteger contas, bancos de dados ou informações sensíveis.
